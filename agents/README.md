# agents

Агенты для Claude Code. Каждый агент — это `.md` файл с YAML frontmatter
(`name`, `description`), за которым следует системный промпт агента.

## Формат файла

```markdown
---
name: agent-name
description: Когда вызывать этого агента и что он умеет.
---

Ты — <роль>. <Системный промпт: задачи, стиль, ограничения>.
```

- `name` — в kebab-case, совпадает с именем файла без `.md`.
- `description` — когда оркестратор должен делегировать задачу этому агенту.
- Тело файла — системный промпт, задающий поведение агента.

## Создать нового агента

```bash
./scripts/new-item.sh agent my-agent-name
```

Шаблон: [`_template.md`](_template.md).
