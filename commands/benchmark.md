# benchmark

Запусти бенчмарк для `$ARGUMENTS` и сравни варианты.

## Шаги

1. Определи что бенчмаркать (функция, CLI-команда, API-вызов).
2. Выбери инструмент:
   - Python: `timeit` — `python3 -m timeit -n 1000 '<expression>'`
   - Node: `console.time` / `bench` из `@vitest/bench`
   - Go: `func BenchmarkXxx(b *testing.B)` + `go test -bench=.`
   - CLI: `hyperfine 'cmd1' 'cmd2' --warmup 3`
3. Запусти минимум 3 прогона; игнорируй первый (прогрев).
4. Сравни варианты по mean/p99; укажи относительное ускорение.

## Результат

Таблица: вариант | mean | p95 | относительно базы. Вывод: какой вариант лучше и на сколько.
