# check-types

Запусти проверку типов и выдай сводку ошибок.

## Шаги

1. Определи тайп-чекер:
   - TS: `npx tsc --noEmit`
   - Python: `pyright .` или `mypy .`
   - Go: `go vet ./...`
   - Rust: `cargo check`
2. Запусти; собери вывод.
3. Сгруппируй ошибки по файлу и типу ошибки.
4. Выдели топ-3 самых частых типа ошибок.
5. Для ошибок `$ARGUMENTS` (если указано) — разбери подробно с предложением фикса.

## Результат

Сводка: N ошибок в M файлах, топ типов → для указанных файлов подробный разбор.
