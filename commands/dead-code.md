# dead-code

Найди мёртвый код в проекте (`$ARGUMENTS` — путь/расширение, или весь проект).

## Шаги

1. Определи инструмент по стеку:
   - TS/JS: `npx ts-prune` (неиспользуемые экспорты), `npx eslint --rule no-unused-vars`.
   - Python: `vulture .` или `pylint --disable=all --enable=W0611,W0612`.
   - Go: `go vet ./...` + `staticcheck`.
2. Запусти и собери вывод.
3. Отфильтруй ложные срабатывания: публичное API, точки входа, тест-хелперы.
4. Сгруппируй по типу: неиспользуемые импорты, функции, переменные, экспорты.

## Результат

Таблица: файл:строка | тип | имя | рекомендация (удалить / проверить вручную).
