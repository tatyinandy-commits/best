# diff-stats

Выведи читаемую сводку изменений: сколько файлов, строк, какие области затронуты.

## Шаги

1. Если задан диапазон в `$ARGUMENTS` — `git diff --stat $ARGUMENTS`.
   Иначе `git diff --stat HEAD` (незакоммиченное) или `git diff --stat origin/main...HEAD`.
2. Сгруппируй файлы по директориям/областям.
3. Выдели: самые большие изменения, новые файлы, удалённые файлы.
4. Укажи итого: файлов изменено, строк добавлено/удалено.

## Результат

Сводка по областям + итоговые цифры. Короткая таблица, без лишних строк.
