# env-check

Проверь, что все нужные переменные окружения заданы.

## Шаги

1. Найди эталонный файл: `.env.example`, `.env.template`, или `env.example`.
2. Извлеки список ключей (без значений).
3. Для каждого ключа проверь: задан ли он в текущем окружении (`printenv KEY`).
4. Разбей результат на:
   - Заданы ✅
   - Не заданы / пустые ❌
   - Заданы в `.env` но не в примере ⚠️ (возможно недокументированные).

## Результат

Таблица: переменная | статус | рекомендация. Список блокеров вверху.
