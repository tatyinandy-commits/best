# explain-code

Объясни код из `$ARGUMENTS` (файл, функция или выделенный фрагмент) понятно и
по делу.

## Шаги

1. Прочитай цель и её ближайший контекст (вызовы, типы, зависимости).
2. Дай объяснение в три слоя:
   - Одной фразой: что это делает и зачем.
   - По шагам: ключевая логика и поток данных.
   - Детали: краевые случаи, допущения, побочные эффекты.
3. Отметь подозрительные места или потенциальные баги, если заметил.

## Результат

Структурированное объяснение (фраза → шаги → детали) + замечания, если есть.
