# find-todos

Найди и систематизируй технический долг, помеченный в комментариях.

## Шаги

1. Поиск меток: `grep -rnE 'TODO|FIXME|HACK|XXX|BUG' --include='*.*' .`
   (исключи зависимости/билды: `node_modules`, `dist`, `.git`).
2. Для каждой метки покажи `файл:строка` и текст комментария.
3. Сгруппируй по типу (FIXME/BUG — выше приоритет, TODO — ниже).
4. По возможности оцени серьёзность по контексту вокруг.

Доп. фильтр пути/метки: `$ARGUMENTS`.

## Результат

Таблица: приоритет | файл:строка | метка | суть. Краткое резюме сверху.
