# git-undo

Отмени последнее действие в git. Опция из `$ARGUMENTS`: `commit`, `stage`,
`push`, `merge` — или определю автоматически.

## Шаги

1. Определи что нужно отменить:
   - Последний коммит (не запушенный) → `git reset HEAD~1 --soft` (сохраняет изменения).
   - Стейдж файла → `git restore --staged <file>` или `git reset HEAD <file>`.
   - Изменения в файле → `git restore <file>` (необратимо! предупрежу).
   - Запущенный коммит → `git revert HEAD` (создаёт новый коммит-отмену, безопасно).
   - Слияние → `git merge --abort` (в процессе) или `git revert -m 1 <merge-sha>`.
2. Предупрежу о необратимых операциях; для деструктивных — запрошу подтверждение.
3. Покажу `git log --oneline -3` и `git status` после.

## Результат

Состояние git после отмены + что именно было сделано.
