# lint-fix

Запусти авто-фикс линтера и форматтера для `$ARGUMENTS` (файл/директория, или
весь проект если не указано).

## Шаги

1. Определи инструменты:
   - TS/JS: `npx eslint --fix` + `npx prettier --write`
   - Python: `ruff check --fix` + `ruff format` (или `black` + `isort`)
   - Go: `gofmt -w`, `goimports -w`
   - Rust: `cargo fmt`
2. Запусти авто-фикс.
3. Покажи `git diff --stat` — что изменилось.
4. Если остались неавтофиксируемые ошибки — перечисли их отдельно.

## Результат

Файлы отформатированы + список того, что нужно исправить вручную.
