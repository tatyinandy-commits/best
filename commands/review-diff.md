# review-diff

Отревьюй незакоммиченные изменения (или указанный диапазон) и выдай
приоритизированные находки.

## Шаги

1. Собери diff: `git diff` (или `git diff $ARGUMENTS`, если задан диапазон).
2. Пройди по изменениям: корректность → безопасность → сопровождаемость.
3. Для каждой находки укажи `файл:строка`, severity и предложение.
4. Игнорируй то, что поправит форматтер.

## Результат

Список находок по severity + краткое резюме и вердикт (ok / нужны правки).
