# scaffold-test-file

Создай заготовку тестового файла для цели из `$ARGUMENTS`.

## Шаги

1. Определи тест-фреймворк и расположение тестов по существующим примерам.
2. Создай файл с правильным именем/путём (например, `test_<module>.py`,
   `<module>.test.ts`).
3. Сгенерируй каркас: импорт цели, фикстуры/setup, пустые тесты с именами под
   ключевые случаи (счастливый путь, границы, ошибки) и пометками TODO.
4. Не пиши логику тестов — только структуру для заполнения.

## Результат

Готовый к заполнению тестовый файл + список предложенных тест-кейсов.
