# summarize-pr

Сделай сжатое и точное резюме изменений для ревью.

## Шаги

1. Собери изменения: `git diff <base>...HEAD` (база из `$ARGUMENTS` или
   основная ветка по умолчанию).
2. Сгруппируй по областям/модулям, а не по файлам.
3. Опиши: что изменилось, зачем, заметные решения и компромиссы.
4. Отметь рискованные места, на которые ревьюеру стоит обратить внимание.
5. Не пересказывай каждую строку — только суть.

## Результат

Резюме: «Что» (по областям) → «Почему» → «На что смотреть при ревью».
