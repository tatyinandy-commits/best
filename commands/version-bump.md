# version-bump

Подними версию проекта. Тип из `$ARGUMENTS` (major/minor/patch) или patch по умолчанию.

## Шаги

1. Найди файл с версией: `package.json`, `pyproject.toml`, `Cargo.toml`,
   `build.gradle` или другой манифест.
2. Вычисли новую версию по semver:
   - `patch`: x.y.Z+1 (багфикс).
   - `minor`: x.Y+1.0 (новая функциональность, обратная совместимость).
   - `major`: X+1.0.0 (breaking change).
3. Обнови версию в манифесте.
4. Добавь в CHANGELOG.md заголовок новой версии с датой (если файл есть).
5. Покажи что изменилось и предложи закоммить с сообщением `chore: bump version to vX.Y.Z`.

## Результат

Обновлённый манифест + заголовок в CHANGELOG + предлагаемое сообщение коммита.
