# write-tests

Напиши сфокусированные тесты для цели из `$ARGUMENTS` (файл, функция или модуль).

## Шаги

1. Найди тест-фреймворк и конвенции проекта по существующим тестам.
2. Определи поведение цели и краевые случаи.
3. Напиши тесты: счастливый путь, границы, ошибки.
4. Изолируй внешние зависимости; тесты должны быть детерминированными.
5. Запусти тесты и убедись, что они проходят (или падают осмысленно для бага).

## Результат

Готовый тестовый файл + команда запуска + перечень покрытых случаев.
