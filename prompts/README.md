# prompts

Промпты и заметки в свободном формате markdown. Сюда складываются
переиспользуемые промпты, наработки, черновики и любые текстовые заметки,
которые не привязаны к строгому формату скиллов/агентов/команд.

## Формат

Свободный markdown. Рекомендуемая шапка для навигации:

```markdown
# Заголовок

> Назначение: одна строка о том, для чего этот промпт.
> Теги: #тема #контекст
```

## Создать новую заметку

```bash
./scripts/new-item.sh prompt my-note-name
```

Шаблон: [`_template.md`](_template.md).
