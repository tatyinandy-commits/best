# code-kata

> Назначение: структурированная практика навыков через решение небольших задач
> с разбором и улучшением решения.
> Теги: #learning #practice #coding

## Контекст

Используй для целенаправленной практики конкретных навыков (алгоритмы,
функциональный стиль, тестирование).

## Промпт

```
Дай мне ката для практики: [тема — алгоритмы / TDD / FP / рефакторинг].
Уровень: [beginner / intermediate / advanced].

После того как я решу, проведи разбор:
1. Корректность: все ли случаи покрыты?
2. Сложность: время и память — можно ли лучше?
3. Стиль: читаемость, идиоматичность для языка.
4. Альтернативы: как ещё можно решить и чем отличается?
Затем дай следующую ката чуть сложнее.
```

## Заметки

Для TDD-ката: сначала тест — потом код. Для рефакторинг-ката: дай плохой код,
я его улучшаю.
