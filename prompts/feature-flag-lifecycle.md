# feature-flag-lifecycle

> Назначение: управление жизненным циклом feature flag — от создания до удаления
> после полной раскатки.
> Теги: #feature-flags #process #cleanup

## Контекст

Используй при планировании раскатки новой фичи через флаги или при очистке
устаревших флагов.

## Промпт

```
Помоги спланировать жизненный цикл feature flag для фичи: [описание].
Проработай этапы:
1. Создание флага: имя (snake_case), тип (boolean/variant), дефолт.
2. Раскатка: этапы (internal → canary → % пользователей → 100%).
3. Метрики: как поймём что раскатка успешна? Что отслеживаем?
4. Rollback-план: как откатиться, если что-то пошло не так.
5. Удаление: когда флаг можно считать мёртвым? Что чистить в коде?
Добавь tech debt-задачу на удаление флага с конкретным сроком.
```

## Заметки

Стыкуется с `dead-code-hunter` (поиск устаревших флагов) и `scope-creep-guard`.
