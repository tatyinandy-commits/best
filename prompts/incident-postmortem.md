# incident-postmortem

> Назначение: каркас безвинного постмортема инцидента.
> Теги: #incident #process #sre

## Контекст

Используй после инцидента, чтобы зафиксировать факты и извлечь уроки без поиска
виноватых.

## Промпт

```
Помоги составить blameless postmortem. Заполним по разделам:
1. Краткое описание (что произошло, влияние, длительность).
2. Хронология (UTC): обнаружение → диагностика → митигация → восстановление.
3. Первопричина (технически точно, без обвинения людей).
4. Что сработало / что усложнило реагирование.
5. Action items: конкретные, с владельцем и приоритетом (детект, защита, процесс).
Тон — фактический и безвинный. Различай первопричину и триггер.
```

## Заметки

Хорошо стыкуется со скиллом `log-triage` (сбор фактов) и агентом
`security-auditor` (если инцидент связан с безопасностью).
