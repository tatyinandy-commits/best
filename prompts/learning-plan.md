# learning-plan

> Назначение: составить персональный план изучения технической темы с
> измеримыми результатами и конкретными ресурсами.
> Теги: #learning #career #skill-building

## Контекст

Используй когда хочешь освоить новую технологию/область системно, а не просто
«читать туториалы».

## Промпт

```
Составь план изучения: [тема]. Мой уровень: [beginner/intermediate/advanced].
Цель: [чего хочу достичь]. Время в неделю: [часов].

Структура плана:
1. Краткий путь (что нужно знать минимально чтобы быть продуктивным).
2. Этапы с конкретными результатами («после этапа я смогу...»).
3. Для каждого этапа: ресурсы (конкретные книги/курсы/docs), практика, проект.
4. Как понять что этап пройден (измеримый критерий).
5. Типичные заблуждения и ловушки в начале пути.
Убери всё что «неплохо знать» — только необходимое для цели.
```

## Заметки

Стыкуется с `technical-interview-prep` если цель — пройти интервью.
