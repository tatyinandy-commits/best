# onboarding-checklist

> Назначение: чек-лист онбординга нового разработчика в проект — от клонирования
> до первого PR.
> Теги: #onboarding #process #team

## Контекст

Используй при подготовке онбординга нового члена команды или при самостоятельном
погружении в незнакомый проект.

## Промпт

```
Составь чек-лист онбординга разработчика в этот проект. Разбей по фазам:
1. Доступы и среда (репозиторий, CI/CD, секреты, инструменты).
2. Понимание архитектуры (домены, ключевые потоки данных, зависимости).
3. Запуск локально (setup, тесты, dev-server).
4. Первое знакомство с кодом (прочитать X, разобрать Y).
5. Первая задача (низкий риск, реальная ценность).
6. Процессы команды (ревью, деплой, инциденты, коммуникация).
Для каждого пункта: что конкретно сделать, где взять инфу, кто помогает.
```

## Заметки

Результат — живой документ: обнови по итогам онбординга нового человека.
