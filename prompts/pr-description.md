# pr-description

> Назначение: сгенерировать чёткое описание pull request из diff/коммитов.
> Теги: #git #review #writing

## Контекст

Используй перед открытием PR, чтобы описание было информативным для ревьюера.

## Промпт

```
На основе diff ветки и сообщений коммитов составь описание PR:
- Заголовок: краткий, в повелительном наклонении.
- "Что сделано": 3-6 пунктов по сути изменений.
- "Зачем": проблема/мотивация.
- "Как проверить": конкретные шаги/команды.
- "Риски/заметки": побочные эффекты, что НЕ вошло.
Пиши лаконично, без воды. Не выдумывай изменений вне diff.
```

## Заметки

Связан с командой `/commit` и агентом `code-reviewer`.
