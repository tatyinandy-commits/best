# technical-interview-prep

> Назначение: подготовка к техническому интервью по конкретной теме или роли.
> Теги: #interview #learning #career

## Контекст

Используй для систематической подготовки к техническому интервью — не зубрёжки,
а понимания.

## Промпт

```
Помоги подготовиться к техническому интервью. Тема/роль: [указать].
Сделай:
1. Топ-10 наиболее вероятных вопросов (концептуальных и практических).
2. Для каждого — эталонный ответ с примером/аналогией.
3. Типичные ловушки и уточняющие вопросы от интервьюера.
4. 2-3 задачи на кодирование/дизайн с разбором подхода.
5. Вопросы, которые стоит задать интервьюеру.
Фокус на понимании, а не на заучивании ответов.
```

## Заметки

Для алгоритмических интервью отдельно разберите: время/память, edge-кейсы,
проговаривание вслух.
