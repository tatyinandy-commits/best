# user-story-splitter

> Назначение: разбить крупную пользовательскую историю на маленькие, ценные и
> независимо поставляемые истории.
> Теги: #agile #planning #product

## Контекст

Используй, когда история слишком большая для одного спринта/итерации и её нужно
нарезать без потери ценности.

## Промпт

```
Помоги разбить большую историю на меньшие по принципу INVEST (Independent,
Negotiable, Valuable, Estimable, Small, Testable). Применяй паттерны нарезки:
- по шагам рабочего процесса;
- по бизнес-правилам/вариантам;
- по типам данных/входов;
- happy path сначала, краевые случаи потом;
- CRUD-операции по отдельности.
Для каждой получившейся истории дай: формулировку «Как <роль>, я хочу <…>,
чтобы <…>» и критерии приёмки. Каждая история должна нести самостоятельную
ценность.
```

## Заметки

Стыкуется с `estimation-breakdown` для последующей оценки нарезанных историй.
