# cron-validate

## Назначение

Проверка и объяснение cron-выражений.

## Шаги

1. Разбери выражение по полям:
   - 5 полей: `мин час день-месяца месяц день-недели`
   - 6 полей (с секундами): `сек мин час ...` (Quartz/Spring)
2. Объясни: «Запускается каждые X / в X:Y каждый Z».
3. Проверь на типичные ошибки:
   - `0 0 31 2 *` — 31 февраля (никогда не сработает).
   - `*/1 * * * *` — каждую минуту (желательно ли?).
   - `0 0 * * 7` — воскресенье (0 или 7, зависит от cron-реализации).
4. Предложи человекочитаемое описание и ближайшие N дат срабатывания.

## Примеры объяснений

- `0 2 * * *` → «Каждый день в 02:00».
- `*/15 9-17 * * 1-5` → «Каждые 15 минут с 9:00 до 17:00, пн–пт».
- `0 0 1 * *` → «В полночь 1-го числа каждого месяца».
