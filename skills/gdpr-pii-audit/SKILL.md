# gdpr-pii-audit

## Назначение

Аудит обращения с персональными данными (PII) на соответствие GDPR. Это
техническая помощь, **не юридическая консультация** — финальную оценку даёт юрист/DPO.

## Что искать (PII)

Имя, email, телефон, адрес, паспорт/ID, IP, гео, платёжные данные, кошельки —
особенно в контексте инвесторов (KYC-данные = чувствительные).

## Чек-лист GDPR

1. **Минимизация данных:** собирается только необходимое; нет «на всякий случай».
2. **Согласие и основание:** для каждого вида обработки есть правовое основание;
   согласие отзываемо.
3. **Шифрование:** PII шифруется at-rest (БД) и in-transit (TLS); секреты/ключи
   не в коде.
4. **Право на удаление (Art. 17):** есть механизм полного удаления/анонимизации
   по запросу — включая бэкапы, логи, аналитику.
5. **Право на доступ/переносимость (Art. 15/20):** экспорт данных пользователя.
6. **Логи:** не пишут PII в открытом виде (маскирование email/токенов в логах).
7. **Retention:** заданы сроки хранения; устаревшие данные удаляются.
8. **Третьи стороны:** передача данных (аналитика, KYC-провайдеры) задокументирована.

## Технические находки

```bash
# Поиск потенциального PII в логах
grep -rnE '(email|passport|phone|ssn|iban)' --include='*.log' .
# PII в коде/фикстурах
grep -rnE '[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}' src/
```

## Формат вывода

Карта PII (где хранится/логируется) + находки по чек-листу + приоритетные риски.
Пометка: требует ревью DPO/юриста.
