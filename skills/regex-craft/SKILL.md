# regex-craft

## Назначение

Построение, объяснение и отладка регулярных выражений под конкретные примеры.

## Когда использовать

- Нужен паттерн под набор «должно совпасть / не должно».
- Регулярка работает не так — надо разобрать почему.

## Когда НЕ использовать

- Парсинг вложенных/рекурсивных структур (HTML, сбалансированные скобки) —
  используй настоящий парсер.

## Шаги

1. Собери позитивные и негативные примеры — это спецификация.
2. Строй паттерн инкрементально, проверяя на каждом примере.
3. Якоря (`^`, `$`), границы слов (`\b`), нежадность (`*?`) — по необходимости.
4. Учитывай диалект (PCRE/POSIX/JS/Python) — экранирование и фичи различаются.
5. Объясни итог по частям и предупреди о катастрофическом бэктрекинге.

## Формат вывода

Паттерн + построчное объяснение групп + примеры совпадений/несовпадений.

## Заметки

Избегай вложенных квантификаторов вроде `(a+)+` — риск ReDoS.
