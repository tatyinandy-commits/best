# sql-optimize

## Назначение

Анализ и оптимизация медленных SQL-запросов.

## Когда использовать

- Запрос работает медленно, нужно понять почему и ускорить.
- Подбор индексов под конкретные запросы.

## Шаги

1. Получи план: `EXPLAIN ANALYZE <query>` (Postgres) / `EXPLAIN` (MySQL).
2. Ищи проблемы: seq scan по большой таблице, неверный порядок join,
   отсутствие индекса, sort/hash на диск, плохие оценки кардинальности.
3. Предложи индексы под предикаты WHERE/JOIN/ORDER BY (учти селективность,
   составные и покрывающие индексы).
4. Перепиши запрос: убери SELECT *, лишние подзапросы, неэффективные OR,
   функции над индексируемыми колонками.
5. Перепроверь планом, что стало лучше; учитывай стоимость записи индексов.

## Формат вывода

Диагноз по плану → предлагаемые индексы → переписанный запрос → ожидаемый эффект.

## Заметки

Оптимизируй под реальные данные/нагрузку; индексы ускоряют чтение, но замедляют
запись.
